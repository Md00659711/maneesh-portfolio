## The challenge

Sherpa is a learning platform for organisations: compliance training, employee onboarding, partner academies and customer education. Its marketing site has to look polished, load fast and let the marketing team publish and change pages quickly, without waiting for a developer and without breaking the design.

## What I built

- **A pure Gutenberg site**: no page builder and no ACF layouts. Every section (hero, platform stages, feature cards, stats, solution sections, calls to action) is a custom native block.
- **Custom blocks written in React** with the WordPress Block API: editor controls, block variations and live previews, so what editors see in the editor matches the live page.
- **A shared design system** through `theme.json` and block styles, so spacing, colours and typography stay consistent on every page.
- **A Bedrock + Composer setup** for a clean, version-controlled codebase.

## Why native blocks

Native Gutenberg blocks render as plain HTML, load fast, and stay editable for years without depending on a page-builder plugin. The marketing team gets real freedom to build pages, and the code stays maintainable.

## Stack

React, the Gutenberg Block API, JavaScript, PHP, WordPress Bedrock, theme.json, SCSS and Git.
